# 微软积分每日任务助手

一个 Chrome 扩展（Manifest V3），自动完成 Microsoft Rewards 的日常任务：

- 首页「每日活动」的 3 个任务
- 「积分赚取」页的日常任务
- 必应搜索连续打卡（配合 Tampermonkey 自动搜索脚本）
- 领取页面上出现的「可领取」积分

支持**手动一键执行**，也支持**每天随机时刻**或**固定间隔 + 随机抖动**自动执行。

> 插件只负责在已登录的浏览器里模拟点击，不处理登录、不保存账号密码。

---

## 功能

| 功能 | 说明 |
| --- | --- |
| 每日活动 | 打开 `rewards.bing.com/dashboard`，展开「每日活动」，逐个点击未完成的卡片（带 referrer，服务端据此计分），任务页停留随机时间后关闭 |
| 积分赚取页日常任务 | 打开 `rewards.bing.com/earn`，在「日常任务」区块逐个点击未完成且带积分徽标的卡片，跳过「已完成」；最多点 10 个 |
| 必应搜索打卡 | 展开「必应搜索连续打卡」卡片，点「立即搜索」→ 新标签页 → 点击油猴脚本的「开始自动搜索」，等脚本结束后关闭标签页 |
| 领取积分 | 搜索打卡后重新加载仪表盘，点右上角「可领取」→ 抽屉里的「领取积分」完成到账 |
| 只领取积分 | 弹窗里独立按钮，不跑任务、不搜索，直接刷新页面把可领取的积分领掉 |
| 定时执行 | 每天窗口内随机时刻 / 固定间隔带抖动；浏览器错过后下次启动补跑 |
| 反馈 | 图标角标显示进度，结束后弹系统通知，弹窗里可查看上次结果与下次运行时间 |

## 执行流程

一次完整执行（弹窗「立即执行每日任务」或定时触发）：

```
1. 打开/刷新首页仪表盘 → 展开「每日活动」→ 逐个点击未完成任务
2. 打开「积分赚取」页 → 点击「日常任务」里未完成、带积分的卡片
3. 回到首页 → 「立即搜索」→ 新标签页 → 触发油猴「开始自动搜索」
4. 搜索结束后刷新首页 → 领取「可领取」积分
5. 回读积分、发通知、还原你原来正在看的标签页
```

每一步都可以在弹窗里单独关闭。

## 安装

1. 下载或克隆本仓库到本地；
2. Chrome 地址栏打开 `chrome://extensions`，开启右上角「开发者模式」；
3. 点击「加载未打包的扩展程序」，选择本目录（含 `manifest.json` 的那一层）；
4. 建议点工具栏的拼图图标，把「微软积分每日任务助手」固定出来。

> **目录在 WSL 里？** Chrome 是 Windows 程序，加载时要选 Windows 能访问的路径，例如
> `\\wsl.localhost\Ubuntu\www\my\ms-rewards-daily`。如果 Chrome 对 UNC 路径报错，就把该目录复制到
> Windows 本地（如 `C:\Tools\ms-rewards-daily`）再加载，改代码后复制过去并点「重新加载」即可。

### 搜索打卡的前置条件

「必应搜索打卡」依赖你已安装的 Tampermonkey 脚本：

- 脚本需包含「开始自动搜索」按钮（脚本自行搜索直到完成）；
- 需在 `www.bing.com` / `cn.bing.com` 启用；
- 如果不想用这一步，在弹窗里取消「完成后触发必应搜索打卡」。

## 使用

- **立即执行**：点扩展图标 → 「立即执行每日任务」。执行期间浏览器会短暂切到相关标签页。
- **只领取积分**：点「只领取「可领取」积分」，只做第 4 步。
- **定时**：勾选「启用定时自动执行」，展开「定时设置」选择模式与参数后保存。

### 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 启用定时自动执行 | 开 | 关闭后只保留手动触发 |
| 执行模式 | 每天一次 | 每天窗口内随机时刻；或固定间隔 + 抖动 |
| 随机时间窗口 | 08:00–22:00 | 每天在此窗口内随机选一个时刻执行 |
| 执行间隔 | 240 分钟 | 间隔模式使用 |
| 随机抖动 | ±15% | 间隔模式使用，让时间点更自然 |
| 任务页停留 | 12–25 秒 | 点开的任务页停留多久再关闭 |
| 完成后点击「积分赚取」页日常任务 | 开 | 流程第 2 步 |
| 完成后触发必应搜索打卡 | 开 | 流程第 3 步 |
| 等待自动搜索脚本结束 | 15 分钟 | 超时后搜索标签页保持打开，脚本可能仍在运行 |
| 完成后领取「可领取」积分 | 开 | 流程第 4 步 |

### 定时行为说明

- 每天模式：窗口内随机一个时刻；今天已成功执行过则排到明天。
- 间隔模式：`间隔 × (1 ± 抖动)` 随机取值，最小 1 分钟。
- 补跑：Chrome 启动时若计划时刻已过且今天没跑过，会立即补跑一次。
- 最小提前量：任何下次执行时间至少在当前时间 15 秒之后。

## 工作原理

- 每日活动卡片必须**从仪表盘真实点击**才会计分（服务端校验来源），因此内容脚本在页面上模拟点击卡片本身，而不是直接打开任务链接。
- 页面是 React 懒渲染：脚本会展开折叠区块、滚动进视口并轮询等待节点出现；每次操作都重新查询 DOM，避免引用失效。
- 后台标签页的定时器会被 Chrome 节流，所以执行前会先把目标标签页切到前台、必要时还原最小化窗口，结束后再切回原来的标签页。
- 积分赚取页的卡片会按文字识别：跳过包含「已完成」的；若能识别到积分徽标，则只点带积分的卡片。
- 领取积分按文案识别：「领取」通常是个没有 `role` 的 `div`，点击后出现右侧抽屉，需再点「领取积分」才到账；脚本会跳过「查看领取记录」「领取更多积分」「已领取」等干扰项。
- 所有步骤都有上限（任务数、点击次数、超时），重复执行不会重复得分（服务端去重），多跑几次是安全的。

## 常见问题

**Q：弹窗显示「搜索打卡：未触发油猴」？**
Tampermonkey 未启用、脚本未在该站点运行，或脚本里没有「开始自动搜索」按钮。手动打开一次必应确认按钮存在。

**Q：弹窗显示「领取：无可领取项」，但页面上确实有？**
多半是页面文案或结构变了。把「可领取」那块截图提 issue，或在 DevTools 里看一下按钮文字。

**Q：改了代码，版本号没变？**
`chrome://extensions` 里点该卡片的「重新加载」；若仍不生效，完全退出 Chrome（含托盘）再打开。

**Q：执行时会把浏览器切走？**
会短暂激活相关标签页（后台标签页会被节流），结束后切回你原来的标签页。

**Q：答题/投票类任务会自动作答吗？**
不会。插件只点开任务页并停留，不会代答；得分以微软实际发放为准。

## 目录结构

```
ms-rewards-daily/
├── manifest.json    # MV3 清单（权限、内容脚本、弹窗）
├── background.js    # 调度、执行流程、标签页与通知
├── content.js       # 仪表盘/赚取页：点任务、立即搜索、领取积分
├── bing.js          # 必应搜索页：触发油猴「开始自动搜索」
├── popup.html/js/css# 弹窗：状态、手动按钮、设置
└── icons/           # 16/48/128 图标
```
